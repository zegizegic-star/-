МОИ ФИНАНСЫ — программа для учёта трат
========================================

Что это
-------
Настольная программа для Windows: операции (доходы/расходы), категории
с лимитами бюджета, копилки (накопления), регулярные платежи (подписки,
аренда, зарплата), графики и отчёты. Все данные хранятся у вас на
компьютере в файле finance_data.db и никуда не отправляются — кроме
одного необязательного случая: если вы сами загружаете фото чека на
вкладке «Чеки», это фото по вашему запросу уходит в облачный сервис
распознавания OpenAI (GPT) с вашим собственным API-ключом. Без этой
функции интернет программе не нужен.

Как превратить это в обычную программу (.exe) — 3 шага
--------------------------------------------------------

1. Установите Python (если ещё не установлен)
   Скачайте с сайта https://www.python.org/downloads/ (кнопка "Download Python").
   Во время установки ОБЯЗАТЕЛЬНО поставьте галочку внизу первого окна:
   "Add python.exe to PATH". Затем нажмите "Install Now".

2. Соберите программу
   Дважды кликните на файл build.bat в этой папке.
   Откроется чёрное окно, которое само установит нужные библиотеки
   и соберёт программу. Это займёт пару минут — просто дождитесь
   надписи "Готово!".

3. Запустите программу
   Зайдите в появившуюся папку dist — там будет папка МоиФинансы, а
   внутри неё — МоиФинансы.exe. Скопируйте ВСЮ папку МоиФинансы
   целиком (не только exe-файл!) куда угодно (например, на Рабочий
   стол) и запускайте exe-файл внутри неё двойным кликом.
   При желании можно создать ярлык на Рабочем столе (правой кнопкой
   по exe-файлу → "Отправить" → "Рабочий стол (создать ярлык)").
   Программа собирается в виде папки, а не одного файла, специально:
   так Windows не распаковывает библиотеки во временную папку при
   каждом запуске, и антивирусы/политики безопасности реже принимают
   программу за подозрительную.

Важно про данные
----------------
При первом запуске рядом с exe-файлом (внутри той же папки МоиФинансы)
создастся файл finance_data.db — в нём хранятся все ваши операции,
категории и копилки. Если захотите перенести программу на другой
компьютер — скопируйте всю папку МоиФинансы целиком вместе с
finance_data.db, и все данные переедут вместе с ней.
Дополнительно программа сама создаёт резервные копии: при каждом
запуске рядом появляется папка backups с копией finance_data.db
(хранятся последние 5 копий). Чтобы вручную сделать копию — просто
скопируйте finance_data.db в надёжное место.

Если Windows блокирует exe-файл ("Интеллектуальное управление
приложениями заблокировало приложение...")
--------------------------------------------------------------------
Это отдельная защитная функция Windows 11 (Smart App Control) — она
блокирует любые exe-файлы без цифровой подписи известного издателя,
без возможности нажать "Всё равно запустить". Если отключить её в
Параметры → Конфиденциальность и защита → Безопасность Windows →
Управление приложениями и браузером не получается (страница сама
закрывается — так бывает, если это ограничено политикой на устройстве),
запускайте программу напрямую через Python, без сборки exe:

1. Установите Python, как описано в шаге 1 выше.
2. Откройте командную строку в этой папке и выполните:
   pip install -r requirements.txt
3. Дважды кликните на файл МоиФинансы.pyw в этой папке — программа
   откроется без отдельного окна консоли.
   Можно создать ярлык: правой кнопкой по МоиФинансы.pyw →
   "Отправить" → "Рабочий стол (создать ярлык)".

Такой запуск делает ровно то же самое, что и exe (те же данные, те
же функции) — просто вместо отдельной программы её код выполняет уже
установленный на компьютере Python, а его Windows не блокирует.

Возможности программы
----------------------
• Дашборд: доход/расход/баланс за месяц, баланс за всё время,
  прогресс по бюджету каждой категории, круговая диаграмма расходов,
  график динамики доходов и расходов за 6 месяцев.
• Операции: добавление, редактирование и удаление доходов/расходов
  с датой, категорией и заметкой; поиск по операциям; экспорт всех
  операций в Excel или CSV (кнопка "Экспорт в Excel/CSV").
  Горячие клавиши: Enter в форме — добавить операцию (или сохранить
  изменения при редактировании), Delete на выбранной строке списка —
  удалить операцию (после подтверждения).
• Категории: свои категории расходов и доходов, лимит бюджета в месяц,
  свой цвет, редактирование и удаление.
• Копилки: цели накоплений с прогресс-баром, пополнение, изменение
  цели, удаление.
• Регулярные платежи: подписки, аренда, зарплата и т.п. — при запуске
  программы в нужный день месяца операция добавится в "Операции"
  автоматически.
• Годовой отчёт: отдельная вкладка со сводкой за весь год (доход,
  расход, баланс, средний расход в месяц), расходами по категориям
  и графиком доходов/расходов по всем 12 месяцам года; переключение
  года кнопками "◀" / "▶".
• Резервное копирование: при каждом запуске программы рядом с
  finance_data.db создаётся её копия в папке backups (с датой и
  временем в имени файла). Хранятся последние 5 копий — более старые
  удаляются автоматически. Если что-то случится с основной базой,
  просто скопируйте нужный файл из backups обратно в finance_data.db.
• Своя иконка приложения (icon.ico) вместо стандартной — видна и
  на панели задач, и на самом exe-файле.
• Поддержка кириллицы: программа корректно работает, даже если путь
  к файлу (папка на рабочем столе, имя пользователя Windows и т.п.)
  содержит русские буквы.
• Чеки: на вкладке «Чеки» можно загрузить фото или скан чека — сумма,
  дата, магазин и подходящая категория распознаются автоматически.
  Перед сохранением открывается окно проверки, где всё можно поправить.
  Фото чека сохраняется в папку receipts рядом с finance_data.db —
  имя файла содержит номер операции, поэтому чек всегда можно найти.
  Для распознавания нужен свой API-ключ OpenAI (кнопка «⚙ Настройки
  распознавания» на той же вкладке; получить ключ можно на
  platform.openai.com/api-keys). Ключ хранится только на этом
  компьютере, в файле receipt_config.json — эти два файла
  (receipt_config.json и папка receipts) не стоит выкладывать в общий
  доступ или в Git, так как в ключе — доступ к вашему аккаунту OpenAI,
  а в чеках — личные данные о покупках.

• Счета и переводы: можно завести несколько счетов (наличные, карта,
  вклад и т.п.), у каждого свой баланс. Операции привязываются к счёту,
  между счетами можно делать переводы (перевод не считается ни доходом,
  ни расходом). Счёт с операциями на нём удалить нельзя.
• Умное автозаполнение категории: если заметка совпадает с уже
  встречавшейся раньше, категория для новой операции подставляется
  автоматически.
• Поиск по всем операциям: в «Операциях» можно включить переключатель
  «за всё время», чтобы поиск шёл не только по текущему месяцу.
• Предупреждение о превышении лимита: если новая трата выведет
  категорию за месячный лимит, программа спросит подтверждение и
  покажет, насколько будет превышен лимит.
• Копилки с дедлайном: у цели накопления можно указать желаемую дату
  и увидеть, сколько нужно откладывать в месяц, чтобы успеть к сроку.
• Импорт банковской выписки: на вкладке «Операции» можно загрузить
  выписку из интернет-банка (CSV или Excel) — программа сама
  попробует угадать колонки с датой, суммой и описанием, а если не
  получится — их можно выбрать вручную перед импортом. Есть также
  кнопка «✨ Распознать через ИИ» — вместо угадывания колонок вся
  выписка (без фото, только табличные данные) отправляется в OpenAI
  для разбора. Использует тот же API-ключ, что и распознавание чеков
  («⚙ Настройки распознавания» на вкладке «Чеки»). Обычный локальный
  разбор бесплатный и не отправляет ничего в интернет — используйте
  ИИ-вариант, только если обычный не справился с колонками вашего
  банка. Есть галочка «Пропускать переводы между своими счетами» —
  включена по умолчанию, отсеивает операции вроде «перевод между
  счетами одного клиента», которые не являются настоящим доходом
  или расходом.
• Обнаруженные подписки: на вкладке «Регулярные» программа сама
  находит среди уже сохранённых расходов те, что повторяются с почти
  одинаковой суммой (похоже на подписки — Яндекс Плюс и т.п.), и
  показывает список с оценкой общей суммы в месяц. Кнопкой
  «+ В регулярные» найденную подписку можно одним кликом превратить
  в настоящий регулярный платёж.
• Прогноз баланса: на дашборде показывается ожидаемый баланс на конец
  месяца исходя из того, как расходуются деньги сейчас (простая
  линейная оценка — в начале месяца после крупного разового платежа,
  например аренды, прогноз может выглядеть излишне тревожным, это
  нормально).
• Прикрепление чека к любой операции: помимо автоматического
  распознавания на вкладке «Чеки», к любой операции в списке можно
  вручную прикрепить фото чека кнопкой «Прикрепить чек».
• Проверка обновлений: при запуске программа один раз тихо проверяет,
  не вышла ли новая версия на GitHub, и если да — показывает ссылку
  на неё. Если интернета нет или GitHub недоступен — просто ничего
  не показывает, работе программы это не мешает.
• Новый дизайн: боковое меню вместо вкладок сверху, современная
  светлая тема с акцентным цветом, аккуратные карточки и иконки.

Если что-то пошло не так при сборке
-------------------------------------
Чаще всего проблема в том, что при установке Python не была отмечена
галочка "Add python.exe to PATH" — тогда переустановите Python ещё раз
и обязательно отметьте эту галочку.
